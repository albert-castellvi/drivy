# Road redesign — "carretera, no gimnasio"

Replace the generic fitness/Duolingo look with Drivy's own visual language: the day as a stretch of road (structure, mockup C) speaking Spanish road-signage vocabulary (mockup B), in light and dark mode.
Branch `feat/road-redesign`; delivery: `single-pr`, one commit per task; test runner: XCTest on GitHub Actions `macos-26` (no local Mac, CI is the only compiler).
Reference mockup: `/tmp/claude-1000/-home-acastellvi-personal-Drivy/f9db6393-310d-4119-843d-4171e9899c59/scratchpad/mockups/hoy.html` (variant C layout + variant B signs).

- **S3** Design system (T1 owns it, every screen uses it, nobody re-implements it):
  - **Colors** as dynamic `Color`s (light / dark) in `Drivy/UI/Theme/DrivyColors.swift`:
    `paper` #ECEBE6 / #131416 · `paperRaised` #F6F5F1 / #1D1F21 · `rule` #D6D4CC / #2C2F32 · `ink` #22231F / #ECEAE3 · `inkMuted` #5F5D56 / #A3A097 · `asphalt` #34363A / #3A3E45 · `laneMark` #F4F2EA / #D9D6CC · `signBlue` #0F4C8A / #0F4C8A · `signRed` #C8102E / #C8102E · `alertText` #C8102E / #F25768 · `signFace` #FFFFFF / #F2F0EA · `signGlyph` #1B1B19 / #1B1B19 · `caution` #FFB020 / #FFB020 · `cautionText` #9A4A00 / #FFB84D · `go` #1A6B33 / #4CC77F · `tint` #0F4C8A / #6EA6E8 · `ice` #8FC1E3 / #5E9CC8.
    Signs keep sign colors in both modes (real signs are retroreflective); only `signFace` dims slightly in dark. Red *text* (wrong answers, relegation) uses `alertText`, never `signRed`.
  - **Type**: Barlow (Regular, Medium, SemiBold, Bold) + Barlow Condensed (SemiBold, Bold), OFL, bundled under `Drivy/Resources/Fonts/` with `OFL.txt`, registered in `UIAppFonts`. Roles in `Drivy/UI/Theme/DrivyFonts.swift`, all `Font.custom(_:size:relativeTo:)` so Dynamic Type keeps working: `display` Condensed Bold 44 → .largeTitle · `title` Condensed Bold 26 → .title2 · `headline` Condensed SemiBold 20 → .title3 · `body` Regular 17 → .body · `bodyStrong` SemiBold 17 → .body · `footnote` Regular 13 → .footnote · `kicker` SemiBold 12 → .caption. Numbers use `.monospacedDigit()`. No tracked uppercase eyebrows.
  - **Components** in `Drivy/UI/Road/`: `RoadSign` (prohibition disc, warning triangle, blue info square, speed-limit disc; glyph = SF Symbol or number; sizes 24–64), `KmPost` (hito: white post with colored cap and content: score/day), `RoadTimeline` + `RoadStop` (vertical asphalt band with edge lines and dashed centre line on the leading side, stops pinned on the road; `isMoving` animates the dashes, off under Reduce Motion), `DirectionSignButtonStyle` (primary action: blue sign with arrow tip, white Condensed text, ≥ 44 pt tall), `WarningLamp` (dashboard tell-tale, lit = `caution`, unlit = `inkMuted` at low opacity).
  - **Mappings** shared by every screen: `QuestSign` (quest kind → `RoadSign`) and `EventSign` (drive event kind → `RoadSign`: harsh brake / harsh acceleration → warning triangle, phone use → prohibition disc with phone, speeding → speed-limit disc).
  - `drivyCard()` restyled to `paperRaised` + 1 px `rule` hairline, radius 12, no fill elsewhere; screens prefer proximity and rules over cards.
  - Root applies `.tint(.drivyTint)`, `.font(.drivyBody)` and Barlow Condensed on UINavigationBar titles and tab bar item labels.
- **S4** Forbidden after the redesign (grep-able): SF Symbols `flame`, `sparkles`, `trophy`, `snowflake`, `star` (any variant) in views; `LinearGradient`/`RadialGradient`/`AngularGradient`; `.shadow(`; emoji in UI copy; system blue as accent. The streak freeze ("hielo") is drawn as a `KmPost` with the `ice` cap.
- **S5** Screens (T2–T5): Hoy = road of the day (header: date, score `KmPost`, streak/hielos/XP line; road: "Por delante" pending quests + lesson as signs → "Ahora" with the start/stop action and the live drive → today's drives behind, newest first, with their events as signs); Camino = the same road at week scale; Debrief/DriveDetail = map first, events as signs on the map and in the list, `WarningLamp` summary row; every other screen adopts tokens, type and signs.
- **S6** Invariants: all user-facing copy strings stay byte-identical (tests pin them; new copy only where a new element needs it and never inviting to drive more); view models, scoring, persistence and Supabase calls untouched (new pure presentation helpers allowed, with tests); accessibility from the previous pass must not regress (`@ScaledMetric`/relative fonts, combined VoiceOver elements, 44 pt targets, decorative signs hidden or labelled once); iOS 17 deployment target with iOS 26 Liquid Glass only on fixed chrome behind `#available`; the share card renders through `ImageRenderer` in a fixed light palette with no materials.
- **S7** Light and dark mode both first-class: every text/background pair in S3 meets WCAG AA (≥ 4.5:1, ≥ 3:1 for ≥ 18 pt bold) in both appearances, enforced by a unit test.
- **S8** Visual proof: a design gallery test renders each redesigned screen with fixture data in light and dark through `ImageRenderer` and writes PNGs to `$GALLERY_DIR` when set; CI sets it via `TEST_RUNNER_GALLERY_DIR` and uploads the folder as artifact `design-gallery` on every run. (Map views render blank in `ImageRenderer`; acceptable.)
- **S9** Motion and haptics only where they explain state: road dashes move while a drive is recording; `.sensoryFeedback` on start/stop drive and on quest completion; everything respects Reduce Motion.
